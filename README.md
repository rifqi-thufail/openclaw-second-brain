# Second Brain

Personal knowledge base. PARA principles. Managed in Obsidian. Tracked with git. Backed up to GitHub.

## Structure

- Inbox/: quick captures, unprocessed
- Projects/: active work with a defined outcome and deadline
- Areas/: ongoing responsibilities you maintain over time
- Resources/: topics of interest, references, how-tos
- Archives/: inactive items, moved here when finished
- memory/: daily notes, indexed by the agent for recall
- templates/: note templates
- attachments/: images and files attached to notes

## Rules

- Every note is plain .md, no proprietary formats
- Daily notes live in memory/YYYY-MM-DD.md
- Capture first, organize later. Process Inbox/ regularly
- Finished projects move to Archives/
- Commit often, push to GitHub
